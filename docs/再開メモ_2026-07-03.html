① まず思い出す：これは何をするものか

ケアマネの月間訪問調整を「利用者の名前ピースを月間カレンダーにはめ込む」操作で見える化するアプリ。 ブラウザだけで動く1ファイル（visit-planner.html）で、データはブラウザ内に自動保存されます（サーバー不要）。 今日は1日3枠→4枠への変更と、訪問の種別（モニタリング／担当者会議／その他）の区別を追加し、 Web上にも公開しました。

未配置プール                    月間カレンダー（1日4枠・種別つき）
[山田さん ⚠火NG]                ┌──────────────────┐
[佐藤さん]        ──はめ込む──▶ │ 15(水)      2/4    │
[鈴木さん]                      │ ┃紫 モニタ 山田さん ✓│ 午前①
 …                             │ ┃紺 会議  山田さん ○│ 午前②（同じ人を追加配置）
                                │   午後①            │ ←空き枠クリックで誰でも配置
                                │   午後②            │
                                └──────────────────┘
プール＝「今月モニタリングが済んでいない人」。モニタを置くとプールから消える。
会議やその他は空き枠を直接クリックして配置（プールには影響しない・月に何件でもOK）。
